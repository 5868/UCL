# Urban Consultants Ltd. Website

Responsive static website for GitHub Pages or any standard web host.

## Publish
Upload the contents of this folder to the repository root; `index.html` should be at the root.

## Images
Place JPGs in `assets/images/` using these exact filenames: `img-1.jpg` (hero), `img-2.jpg` (planning), `img-3.jpg` (traffic), `img-4.jpg` (GIS/mapping), `img-5.jpg` (survey), `img-6.jpg` (landscape). Keep `logo.jpg` for the company logo. The links are already in the HTML.

## Before going live
- Add confirmed business email, phone/WhatsApp, office address and social links.
- Replace sample project titles/captions with real project names and publish only authorized work.
- Test navigation, buttons and layout on a real phone after deployment.

Plain HTML, CSS and JavaScript; no build step required.
